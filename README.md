# ca-hmcd-low-altitude-safety

Reproducibility repository for the CA-HMCD low-altitude safety study. It
contains the simulation and public-data adapters, exact and approximate
solver backends, formal experiment protocols, tests, figure source data,
manuscript artifacts, and compact statistical results.

The current unified statistical registry has **1,592 paired comparisons in
316 prespecified Holm families**. The historical public-replay subset has
516 comparisons in 141 families. See `REPRODUCE_CURRENT.md` for the current
evidence layers and `verify_release.py` for a checksum and registry audit.

The repository's `LICENSE` covers the original software. The release terms
for author-generated derived tables, figure source data, and documentation
still require confirmation; third-party source data retain their own terms.
